# Prompt: Build Tool X

Build a small, focused CLI tool called "Tool X" that does the one job described
below. Keep it standalone and well tested.

## Requirements

- Read input from a file path passed as the first argument.
- Produce deterministic output suitable for automation.
- Add tests covering the happy path and at least one error case.
- Document usage in a README.

## Constraints

- No network access.
- No external services or API keys.
- Local, inspectable storage only.

This file exists as a realistic `--prompt` target for RunLedger examples.
